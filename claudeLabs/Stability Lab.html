INFOF305 Stability Lab

Designed by Claude

A nominal trajectory x̄(t) starts at x̄₀. Perturbed trajectories start on a circle of radius δ around it. Stability asks whether staying close at the start guarantees staying close forever. Click the phase plane to move x̄₀.

Stable (Lyapunov)∀ ε > 0 ∃ δ > 0 : ‖x(0) − x̄(0)‖ < δ ⇒ ‖x(t) − x̄(t)‖ < ε for all t ≥ 0
Unstable∃ ε > 0 ∀ δ > 0 ∃ x(0), ‖x(0) − x̄(0)‖ < δ, ∃ t : ‖x(t) − x̄(t)‖ ≥ ε

The ε–δ test

Perturbations are always smaller than ε: the charts test δ = ε/10 … ε/10⁸, so every perturbed trajectory starts inside the ε-tube. Each δ is tried in 8 directions; the distance shown is the worst of the 8.
