A quadratic function V(x) = xᵀPx acts as an “energy” for x′ = f(x). Stability follows from how V changes along trajectories, which needs only f, not the solution. Click the phase plane to start a trajectory; watch V(x(t)) and its time derivative below.

Quadratic Lyapunov functionV(x) = xᵀP x, P = Pᵀ ≻ 0 ⇒ V(0) = 0, V(x) > 0 for x ≠ 0. Level sets are ellipses around the equilibrium.
Derivative along trajectoriesd/dt V(x(t)) = ∇V(x)ᵀ x′ = 2 xᵀP f(x) =: V̇(x).
Linear f = Ax: V̇ = xᵀ(AᵀP + PA)x = −xᵀQ x.
Lyapunov’s theorems (near x = 0)V ≻ 0, V̇ ≤ 0 ⇒ stable. V ≻ 0, V̇ ≺ 0 ⇒ asymptotically stable.
V̇ ≻ 0 and V(x) > 0 arbitrarily close to 0 ⇒ unstable (Chetaev).
